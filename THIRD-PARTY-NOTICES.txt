4. Eclipse Temurin JRE 23
-------------------------

Some TeXlinr distributions for Windows bundle Eclipse Temurin JRE 23,
an OpenJDK-based Java runtime provided by the Eclipse Adoptium project,
so that users can run the application without installing Java
separately. Distributions that consist only of the JAR file do not
contain it.

Project website:
https://adoptium.net/

Temurin 23 binaries:
https://github.com/adoptium/temurin23-binaries/releases

Eclipse Adoptium project and licensing information:
https://projects.eclipse.org/projects/adoptium.temurin

The Temurin distribution contains components covered by different
open-source licenses. The applicable license and copyright notices
are those supplied with the specific Temurin distribution.

Original license files, copyright notices and other legal notices
included with the bundled runtime must be retained.

7. TeX distribution (not bundled)
---------------------------------

TeXlinr does not contain a TeX distribution. To build the PDF preview
it calls the programs latexmk, pdflatex and bibtex of a TeX
distribution that the user has installed separately (for example
MiKTeX, TeX Live or MacTeX). These programs are subject to the
licenses of the respective distribution.
